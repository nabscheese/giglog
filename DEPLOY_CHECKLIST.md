# Deployment checklist

- [ ] Run `supabase/schema.sql`
- [ ] Copy `.env.local.example` to `.env.local`
- [ ] Add Ticketmaster Consumer Key
- [ ] Run `npm install`
- [ ] Run `npm run dev` and create a test account
- [ ] Log a test gig
- [ ] Push to a private or public GitHub repository
- [ ] Import repository into Vercel
- [ ] Add all three environment variables in Vercel
- [ ] Deploy
- [ ] Set Supabase Site URL to the Vercel URL
- [ ] Add Vercel URL to Supabase Redirect URLs
- [ ] Test signup, email confirmation, login and gig creation on the live site
