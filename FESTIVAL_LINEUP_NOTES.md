# Festival lineup selector

## Added
- Ticketmaster festival results now return all embedded attractions as a lineup.
- Selecting a festival automatically combines the Ticketmaster lineup with any matching lineup already stored in GigLog for the same festival/year.
- Artists start unticked so the user can choose only the acts they actually saw.
- Select all, clear all, search/add artist, and manual text editing controls.
- Selected artist count and setlist-found status.
- Festival setlist lookup continues to search only selected artists.

## Fallback behaviour
Some festival listings do not publish a full lineup through Ticketmaster. In that case GigLog uses previously saved festival lineups, then allows manual additions.
